# Deyvide Guilherme

Desenvolvedor de Software focado em soluções para telecomunicações, unindo aplicações web modernas (**TypeScript, Next.js, Laravel**) a ferramentas de automação para redes ópticas (**FTTH/GPON**) e infraestrutura Linux.

---

### Sistemas em Produção (Ten Internet)

Na [Ten Internet](https://github.com/teninternet), atuo no setor de Documentação e Projetos como responsável técnico pelo desenvolvimento de ferramentas internas:

- **NetSentinel**: Plataforma de integridade e auditoria de redes ópticas. Opera com arquitetura BFF em Next.js 16 (React 19), backend headless em Laravel 13 (PHP 8.5) e PostgreSQL 16. O ecossistema roda em contêineres endurecidos (não-root, sistema de arquivos em modo leitura), proxy reverso Nginx e pipeline de deploy contínuo via GitHub Actions.
- **Cálculo de Viabilidade & Engenharia Óptica**: Aplicação em FastAPI, Next.js e TypeScript para cálculo mecânico de ancoragem, viabilidade técnica de campo e emissão de documentação de rede para equipes externas.
- **Automação de Ativos de Rede**: Ferramentas CLI em Python (Netmiko) integradas a equipamentos MikroTik RouterOS para inspeção de rede e provisionamento automatizado de rotinas.

### Open Source

- **[mirror-pulse](https://github.com/deyvideguilherme/mirror-pulse)**: Utilitário em Luau para Noctalia Shell (Wayland/Arch Linux) que monitora latência e sincronização de espelhos da `mirrorlist` do Pacman.
